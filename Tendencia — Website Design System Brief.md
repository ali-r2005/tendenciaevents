# Tendencia — Website Design System Brief

## 1. Brand Identity

The Tendencia website should communicate a balance between two core aspects of the brand:

### Professional Event Management
- Planning
- Coordination
- Reliability
- Corporate clients
- Expertise

### Experience & Emotion
- Surprise
- Motivation
- Inspiration
- Creativity
- Memorable experiences

**Overall visual direction:**  
Professional, modern, confident, energetic, and experience-focused. The design should feel credible for corporate clients while still communicating creativity and emotion.

---

## 2. Typography

The website will use a two-font system.

### Hammersmith One
**Role:** Brand / Display / Headlines

Use for:
- Main headlines
- Section headings
- Brand statements
- Large display text
- Key visual moments

Hammersmith One should provide the brand with personality, character, and a distinctive visual identity.

### Inter
**Role:** Body / Navigation / UI / Buttons

Use for:
- Body text
- Navigation
- Buttons
- Forms
- Labels
- Supporting text
- UI elements

Inter should provide excellent readability and a clean, modern interface.

---

## 3. Brand Colors

### Green — `#147f4c`
**Primary brand color — Identity**

Green should be the main brand/action color.

Use for:
- Primary CTAs
- Important links
- Selected navigation states
- Brand elements
- Section accents

Green should carry the strongest visual connection to the Tendencia brand.

---

### Blue — `#2497cd`
**Secondary color — Supporting personality**

Blue should complement the primary green and add variety to the visual system.

Use for:
- Secondary CTAs
- Informational sections
- Service categories
- Subtle backgrounds
- Illustrations
- Interactive elements

Blue should support the brand without competing with green.

---

### Yellow — `#f4c71a`
**Accent color — Energy**

Yellow should be used selectively to create visual emphasis and moments of energy.

Use for:
- Highlights
- Small accents
- Badges
- Decorative elements
- Important numbers
- Occasional CTA emphasis

**Principle:** Yellow should communicate **"Look here"**, not **"Everything is yellow."**

Its limited use should make important elements stand out.

---

## 4. Color Hierarchy

The overall visual hierarchy should follow:

**Green → Primary / Brand**

**Blue → Secondary / Supporting**

**Yellow → Accent / Attention**

Neutral colors such as white, off-white, dark text, and grays should provide the main backgrounds and text foundation so the three brand colors remain impactful.

---

## 5. Design Direction

The UI/UX design should aim for a balance between:

**Corporate professionalism**  
→ Clean layouts, strong structure, consistency, clarity

**Event experience**  
→ Dynamic visuals, engaging photography, creative compositions, energy

The final experience should feel like **a professional event partner that creates memorable experiences**, rather than a generic corporate agency website.

---

## 6. Border Radius

**Standard radius — `6px`**

All corners across the site (buttons, cards, images, form inputs, containers) should use a consistent 6px border radius, so the interface reads as one deliberate system rather than mismatched components.

---

## 7. Design System Structure

Design System should initially include:

**Foundations**
- Colors
- Typography
- Spacing
- Grid
- Border radius
- Shadows
- Icons

**Components**
- Buttons
- Links
- Navigation
- Cards
- Badges
- UI elements

**Homepage Patterns**
- Header
- Hero
- Services
- Experience/Portfolio sections
- About
- Testimonials
- CTA
- Footer
